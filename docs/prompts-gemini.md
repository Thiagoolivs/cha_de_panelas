# Prompts para gerar as fotos dos presentes no Gemini

Como usar: abra o Gemini, peça uma imagem por vez colando o prompt (pode ser em inglês mesmo, fica melhor), baixe a imagem e salve com o **nome do arquivo** indicado. Depois me mande todas aqui no chat (ou num .zip).

Todos os prompts usam o mesmo estilo, para as 50 fotos ficarem com a mesma cara (fundo creme do convite, luz suave, toque de verde-oliva).
